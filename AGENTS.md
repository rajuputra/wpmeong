# AGENTS.md - WPMeong

Panduan utama untuk semua AI Agent di proyek **WPMeong**.

> **Versi:** 2.2.0

## 🎯 Quick Context

- **Proyek:** WPMeong (WPM + meong) — typing test ID/EN.
- **Deploy:** Firebase Hosting (`https://wpmeong.web.app`).
- **Stack:** Next.js (static export) + TypeScript + Tailwind + Zustand + Recharts + Firebase.
- **Mode Tes:** Time only, 30s & 60s.

## 📚 Aturan Detail

Semua aturan detail telah dimodularisasi ke folder `.agents/rules/`. Antigravity akan otomatis memuatnya. Lihat file-file di sana untuk:

- Konteks proyek & branding
- Stack teknologi & struktur folder
- Kebutuhan fungsional (fitur MVP)
- Standar koding & testing
- Algoritma & metrik inti

**Catatan:** File `CLAUDE.md` juga tetap ada untuk kompatibilitas dengan Claude Code.
